== VERSION AUTOMATIQUE (nouveau) ==
- buildNumber stocke dans android\gradle.properties, incremente a chaque build release.
- versionCode = buildNumber, versionName = 3.0.<buildNumber> (ex 3.0.31).
- MainActivity.java VERSION vient de BuildConfig.VERSION_NAME (plus de hardcode).
- buildFeatures.buildConfig = true ajoute (AGP8 sinon pas de BuildConfig).
- APK signee app-release-3.0.31.apk (la derniere). buildNumber passe a 32 (prochaine = 3.0.32).
- Signer : apksigner sign --ks %USERPROFILE%\.android\debug.keystore --ks-pass pass:android
  --key-pass pass:android --out app-release-<v>.apk app-release-unsigned.apk

== TRAVAUX (menus services STEG/Sonede/Telecom/...) ==
- storage.py : table travaux (id, nom UNIQUE, url, cree_le) + ajouter/lister/supprimer_travail.
- travaux.py : initialiser_defauts() (steg, sonede, telecom, elfekih, binance),
  detecter_demande_travail(), extraire_nom(), extraire_url_message() (nouveau),
  url_pour_nom(), gerer_message().
- app.py : init defauts au demarrage ; hook travaux.gerer_message() dans _traiter_demande
  (intention "travail") ; routes protégées par token :
    GET  /api/travaux            -> liste
    POST /api/travaux {nom,url}  -> ajouter (prefxe https:// si absent)
    DELETE /api/travaux/<id>     -> supprimer
  ; route web /admin (template admin.html, protege par cookie) pour gérer sans code.
- templates/admin.html : page admin (ajouter/retirer travaux).
- Interface embarquee assets/index.html : bouton menu ☰ + panneau overlay listant les
  travaux via fetch /api/travaux (token), clic -> ouvre le site.
- MainActivity.java : pont ouvrirSite(url) -> ouvre navigateur externe (repli WebView).
